# 保留期声明

每个子目录必须在此登记保留多久、依据是什么。缺失会被审计报出。

> 下表是**起始建议**，涉及合规、财务、账号恢复时应按实际要求延长。

| 目录 | 保留 | 依据 | 到期怎么处理 |
| --- | --- | --- | --- |
| `合同/` | 履行完毕后 10 年 | 民事诉讼时效 + 争议追溯 | 人工复核后销毁 |
| `报销/` | 5 年 | 会计凭证保存要求 | 按年批量清理 |
| `税务/` | 10 年 | 税务稽查追溯期 | 不主动清理 |
| `资产/` | 永久 | 资产清单需要历史连续性 | — |
| `证件/` | 永久（换发后旧件保留 3 年） | 身份追溯 | 旧件到期销毁 |
| `健康/` | 永久 | 病史需要长期连续记录 | — |

## 规则

- **只删超出保留期的具体文件，不删整个目录。**
- 销毁前确认没有其他地方引用（报销单据可能被合同或税务材料引用）。
- 唯一副本、不可重开的凭证、账号恢复相关材料，宁可留着。

## 这个域的策略

| 项 | 值 |
| --- | --- |
| 同步 | **禁止**（`sync: never`，审计会反查同步规则） |
| 冷备 | 必须（restic 自带加密） |
| 静态加密 | 依赖 FileVault，不做逐文件加密 |
| 进 git | 否（只有本文件进） |
| 命名 | 自由，中文优先，建议日期在前 |
